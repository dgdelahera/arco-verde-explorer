# Data contract: `public/data/routes.geojson`

Generated by `npm run data` (`scripts/prepare-data.ts`) and committed. The app only reads this file.

```ts
type RouteFeature = GeoJSON.Feature<GeoJSON.MultiLineString, RouteProps>; // [lon, lat], WGS84

type RouteProps = {
  id: string;               // "RC1".."RC13", "RL1".."RL22", "RL4b" (stable, from the official code)
  name: string;             // official route name
  category: "corta" | "larga"; // RC = corta (<=12 km), RL = larga
  municipalities: string[]; // official list
  distanceKm: number | null;   // official "Distancia (km)"
  elevationGainM: number | null; // official "Desnivel (m)"
  type: string | null;      // official "Tipo": "Lineal" | "Circular" | "Ida y vuelta"
  sector: string | null;    // official "Sector" verbatim: "4", "6 y 7", "Todos"
  notice: string | null;    // official warning appended to the route heading after its name, verbatim (e.g. "TEMPORALMENTE NO SEÑALIZADA."); null when none
  warnings: string | null;  // official PRECAUCIONES, null when "No"
  description: string | null; // official DESCRIPCIÓN, verbatim, paragraphs joined by "\n\n"
  gpxUrl: string;           // official, unmodified GPX on comunidad.madrid
  planUrl: string | null;   // official PDF map
  computedLengthKm: number; // DERIVED: length of the original (unsimplified) track, after dropping segments that repeat another segment of the same route (within 5 m)
};

type RoutesFile = GeoJSON.FeatureCollection<GeoJSON.MultiLineString, RouteProps> & {
  metadata: { source: string; sourceUrl: string; extractedAt: string /* YYYY-MM-DD */ };
};
```

Official fields come verbatim from https://www.comunidad.madrid/medio-ambiente/arco-verde; anything not published is `null`, never guessed. The GPX files carry no elevation (`<ele>` empty); elevation comes from a terrain model in a separate file.

# Data contract: `public/data/pois.geojson`

Generated by `npm run pois` (`scripts/prepare-pois.ts`) from one Overpass API query over the route network's bounding box, keeping only features within 300 m of a track. Committed; the app fetches it the first time a POI category is switched on or the search reaches 3 characters.

```ts
type PoiFeature = GeoJSON.Feature<GeoJSON.Point, PoiProps>; // [lon, lat]; ways and relations use their centre

type PoiProps = {
  id: string;            // OSM object, "node/123" | "way/123" | "relation/123" (https://www.openstreetmap.org/<id>)
  name: string | null;   // OSM name tag, trimmed; null when untagged
  category: "fuente"      // amenity=drinking_water (not drinking_water=no, not access=private)
          | "descanso"    // tourism=picnic_site, amenity=shelter except shelter_type=public_transport
          | "transporte"; // railway=station|halt (Cercanías, Metro, Metro Ligero), not funicular/miniature/monorail
};

type PoisFile = GeoJSON.FeatureCollection<GeoJSON.Point, PoiProps> & {
  metadata: { source: "© OpenStreetMap contributors, ODbL"; sourceUrl: "https://www.openstreetmap.org/copyright"; extractedAt: string /* YYYY-MM-DD */ };
};
```

OpenStreetMap data is community-maintained and licensed under the ODbL. The app credits it in the panel footer.

# Data contract: `public/data/elevation.json`

Generated by `npm run elevation` (`scripts/elevation.ts`, also run at the end of `npm run data`) from the committed `routes.geojson`, and committed. Optional for the app: if it is missing or invalid the ficha shows no profile.

```ts
type ElevationFile = {
  metadata: {
    source: string;         // "MDT25 del Instituto Geográfico Nacional (PNOA-LiDAR)"
    sourceUrl: string;      // human-readable product page (scne.es)
    serviceUrl: string;     // WCS endpoint queried: https://servicios.idee.es/wcs-inspire/mdt (coverage Elevacion4258_25, ArcGrid)
    attribution: string;    // "© Instituto Geográfico Nacional"
    licence: string;        // "CC BY 4.0 scne.es"
    licenceUrl: string;
    resolutionM: number;    // DEM grid spacing, 25
    sampleSpacingM: number; // distance between samples along the track, 50
    smoothing: string;      // e.g. "media móvil de 5 muestras"
    retrievedAt: string;    // YYYY-MM-DD the DEM was queried
  };
  routes: Record<string, {  // key = RouteProps.id
    gainM: number;          // DERIVED: sum of rises of the smoothed samples, per track part
    lossM: number;          // DERIVED: sum of drops, same method
    minM: number;           // DERIVED: min/max of the smoothed samples
    maxM: number;
    profile: [distKm: number, eleM: number][]; // smoothed samples, decimated to at most ~300 points, end kept
  }>;
};
```

Method: each track part of the (simplified) geometry is sampled every 50 m, the DEM is interpolated bilinearly at each sample, a centred 5-sample moving average is applied, and gain/loss are summed per part so the jump between disjoint parts is not counted. Distances run across parts (gaps not counted), so the profile length can differ slightly from `computedLengthKm`. The DEM is bare earth: bridges and underpasses show as dips or bumps. The official `elevationGainM` behaves like max − min altitude rather than cumulative gain, so the two are shown side by side and never merged.

# Data contract: `public/data/hazards.geojson`

Generated by `npm run hazards` (`scripts/prepare-hazards.ts`, also run at the end of `npm run data`) from the committed `routes.geojson` and a hand-kept list of official warnings that name a place. Committed. Optional for the app: if it is missing or invalid the map shows no warning markers.

```ts
type HazardFeature = GeoJSON.Feature<GeoJSON.Point, HazardProps>; // [lon, lat], where the marker goes

type HazardProps = {
  id: string;        // stable slug, "puente-marmota"
  title: string;     // short label written for the map, not official
  text: string;      // official text, verbatim substring of routes[0]'s notice, PRECAUCIONES or DESCRIPCIÓN
  routes: string[];  // RouteProps.id of every route the warning applies to; all pass within 300 m of the point
  path: [lon: number, lat: number][] | null; // the stretch of routes[0] between two named places, or null for a single spot
};

type HazardsFile = GeoJSON.FeatureCollection<GeoJSON.Point, HazardProps> & {
  metadata: { source: string; sourceUrl: string; extractedAt: string /* YYYY-MM-DD */ };
};
```

Method: each place is an Overpass statement for the OpenStreetMap feature the official text names. The point is the spot on routes[0]'s track closest to any of that feature's vertices (no farther than 300 m). For a stretch, both ends are snapped onto the same track part, the track between them becomes `path` and the marker goes on its middle vertex. Locations are approximate; the text is not.
